# 🧠 What I Learned

## Ethereum

Ethereum is **not** a cryptocurrency.

Ethereum is a decentralized blockchain capable of executing programs called **Smart Contracts**.

ETH is simply the native currency used to pay for computation on the network.

---

## Bitcoin vs Ethereum

### Bitcoin

Designed primarily to transfer and store value.

Think of Bitcoin as digital money.

### Ethereum

Designed to execute decentralized applications.

Think of Ethereum as a decentralized world computer.

---

## Ethereum Accounts

An Ethereum account has:

- Address
- ETH Balance
- Nonce

There are two types of accounts:

### Externally Owned Account (EOA)

Controlled by a private key.

Examples:

- MetaMask
- Rabby

### Smart Contract Account

Controlled by code.

Cannot sign transactions.

---

## Private Key → Public Key → Address

```
Private Key
      ↓
Public Key
      ↓
Ethereum Address
```

- Private Key = Secret
- Public Key = Generated from the Private Key
- Address = Generated from the Public Key

The address can be shared publicly.

The private key must never be shared.

---

## Transactions

A transaction is a request sent to Ethereum.

A transaction contains information such as:

- Sender
- Receiver
- Value
- Gas
- Nonce
- Data

Transactions are first broadcast to the network.

They are **not immediately added** to the blockchain.

---

## Mempool

The mempool is the waiting area for pending transactions.

```
User

↓

Network

↓

Mempool

↓

Validator

↓

Block

↓

Blockchain
```

---

## Nodes

A Node is simply a computer connected to Ethereum.

Nodes:

- Store a copy of the blockchain
- Verify transactions
- Propagate information across the network

Not every node is a validator.

---

## Validators

Validators are special nodes that have staked ETH.

Their responsibilities include:

- Selecting transactions from the mempool
- Building blocks
- Executing transactions
- Proposing new blocks

Other validators verify the proposed block before it becomes part of the blockchain.

---

## Blocks

A block is a container holding multiple transactions.

A block also contains:

- Block Number
- Previous Block Hash
- Timestamp
- Transactions
- Other metadata

---

## Block Time

Block Time is the average time between two consecutive blocks.

Ethereum targets approximately **12 seconds**.

The block time is a compromise between:

- Speed
- Security
- Decentralization

---

## Why Gas Exists

Gas exists because computation is **not free**.

Every validator executes the same smart contract.

Without Gas:

- Infinite loops
- Spam attacks
- Network congestion

Gas also compensates validators for their work.

---

## Smart Contracts

A Smart Contract is a program deployed on Ethereum.

It:

- Lives on the blockchain
- Has its own address
- Executes deterministically
- Can store data
- Can receive ETH

---

## Why Smart Contracts?

Traditional applications require trusting a company.

Smart Contracts replace trust in people with trust in code.

Benefits:

- Transparency
- Immutability
- Decentralization
- Verifiability

---

## Solidity

Solidity is the programming language used to write Smart Contracts.

Files use the `.sol` extension.

Example:

```
Bank.sol
Lottery.sol
Token.sol
```

---

## Compilation

The Ethereum Virtual Machine (EVM) cannot execute Solidity directly.

Before deployment:

```
Bank.sol

↓

Compiler

↓

Bytecode
+
ABI
```

---

## Bytecode

Bytecode is the machine code executed by the Ethereum Virtual Machine.

The Bytecode is deployed to Ethereum.

---

## ABI

ABI stands for **Application Binary Interface**.

It is **not executable code**.

It describes how applications interact with the Smart Contract.

Libraries like **ethers.js** use the ABI to call contract functions.

# 💡 Biggest Lessons Today

- Ethereum is a blockchain, not a cryptocurrency.
- ETH pays for computation.
- Transactions first enter the mempool.
- Validators build blocks.
- Every validator executes the same code.
- Smart Contracts replace trust in people with trust in code.
- Solidity must be compiled before deployment.
- Bytecode is executed by the EVM.
- ABI is the interface used by applications.
